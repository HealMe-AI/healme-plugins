# Growth HealMe · 정기 보고서

## 먼저 의도를 짧게 확인

- 이전 대화와 현재 요청에서 대상, 기간, 목적을 먼저 읽는다. 이미 알려 준 조건은 다시 묻지 않는다. 여러 스킬을 함께 써도 인터뷰는 한 번만 한다.
- 결과를 바꾸는 핵심 조건이 빠졌을 때만 아래 질문 예시를 상황에 맞게 골라 한 메시지에 1~2개 질문한다. 번호가 긴 질문지나 모든 선택지를 펼친 인터뷰는 하지 않는다.
- 조건이 충분하면 이해한 범위를 한 문장으로 알리고 바로 조회한다. 선택 사항은 합리적인 기본값과 함께 진행한다. 상품 식별이나 기간처럼 잘못 가정하면 다른 결과가 되는 필수 조건은 답을 받은 뒤 해당 조회를 한다. 기다리는 동안 도구 설명·카탈로그는 확인할 수 있다.
- 사용자가 “알아서 해줘”라고 하면 가능한 범위에서 기본값을 정하고 알려 준다. 조회할 수 없는 데이터나 모호한 상품을 임의로 확정하지 않는다. 범위를 정한 뒤 형식·차트 종류 같은 사소한 선호를 연속해서 묻지 않는다.

질문 예시: “보고할 기간과 대상은 무엇인가요? 전체 또는 특정 상품으로 볼 수 있어요.” / “팀 실적 공유용인가요, 의사결정용인가요?”

기간·대상·출력 형식이 이미 있으면 다시 묻지 않는다. 목적만 빠졌다면 실적 공유용 요약을 기본으로 알리고 진행할 수 있다. “주간 보고서”처럼 주기만 있고 사용자에게 맡겨진 경우 최근 완료된 한 주와 직전 주를 기본으로 하며 실제 시작·종료일을 밝힌다. 파일 형식이 없으면 대화 내 Markdown, 파일을 원하면 Markdown 파일을 기본으로 한다. 같은 맥락의 후속 보고서는 합의한 기준을 재사용한다.

## 조회와 계산의 기준

- 연결된 Growth HealMe MCP 도구를 사용한다. 연결이 없으면 플러그인 연결 화면에서 인증된 회사 계정으로 로그인하도록 안내한다. 토큰 복사나 직접 DB 접속으로 우회하지 않는다.
- 데이터 조회와 반환 결과의 계산만 수행한다. DB·설정·광고·목표 수정, 적재·동기화는 수행하지 않는다. 결과 파일 작성은 가능하지만 Slack 전송·공개 게시·일정 등록은 해당 작업에 대한 사용자 요청이 있을 때만 한다.
- `get_reporting_catalog`와 도구 스키마로 실제 상품, 가능한 기간, 집계 정의를 확인한다. 공통 집계를 우선한다. 필요한 조합이 없으면 `get_data_catalog`로 허용 원천의 행 단위·열·결합 규칙을 확인한 뒤 `query_source_data`로 제한된 범위만 조회한다. 임의 SQL이나 지원하지 않는 인자를 만들지 않는다.
- 기간·시간대·데이터 최신성·집계 기준을 표시한다. 미완료일, 환불, 결측, 페이지 제한, 집계 누락을 숨기지 않는다. 누락을 0으로 바꾸지 말고 비교 범위와 분모를 맞춘다. 비율은 가능한 한 합계 분자/분모로 다시 계산한다.
- 서로 다른 조회를 결합할 때 revision·스냅샷과 집계 단위를 확인한다. 맞지 않으면 최신 기준으로 필요한 조회를 다시 하거나 비교 제한을 명시한다. 개인정보와 행 식별자를 불필요하게 출력하지 않는다.

## 작성

1. 보고 목적에 필요한 지표만 골라 `read_sales_report`, `read_product_report`, `read_dashboard_report`와 관련 조회 도구로 집계한다. 제공되지 않는 목표나 과거 스냅샷을 만들어 넣지 않는다. 현재 기준 목표를 과거 시점의 목표로 표현하지 않는다.
2. 전기 비교는 같은 길이·완료 범위·지표 정의를 맞춘다. 전월·전년 비교가 요청됐거나 판단에 필요한 경우 추가하되 기간 차이를 설명한다. 현재 날짜 기준 요약과 지정 과거 기간 수치를 혼동하지 않는다.
3. 합계·비율·비용 구성의 정합성을 점검하고 주요 변화를 선별한다. 원인 설명이 필요하면 원인 분석 또는 광고 분석 절차를 활용하되 사용자에게 인터뷰를 다시 시작하지 않는다.
4. 차트를 요청받으면 검증된 수치로 실제 차트를 생성하고 보고서에 포함하거나 파일로 연결한다. 생성 수단이 없으면 표를 제공하고 차트가 미완성임을 밝힌다. 없는 이미지를 링크하거나 완성됐다고 말하지 않는다.

## 결과와 반복 사용

요약, 핵심 지표와 비교, 주요 변화, 필요한 차트, 다음 확인 항목, 기간·출처·계산 기준·제한을 포함한다. 규모는 사용자가 요청한 깊이에 맞춘다. 파일을 요청했다면 실제 파일을 저장해 링크로 제공한다. “정기 보고서”는 반복 가능한 보고 형식을 뜻하며 자동 실행 예약이나 Slack 전송은 별도 요청이 있을 때만 지원되는 도구로 처리한다.
