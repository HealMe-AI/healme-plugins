# Growth HealMe

- 연결된 Growth HealMe MCP 도구만 사용한다. 인증이 필요하면 플러그인 연결 화면에서 회사 계정으로 로그인한다.
- 데이터·설정 수정, 적재, 동기화 작업은 수행하지 않는다. 인증이나 조회 권한을 우회하지 않는다.
- 서버의 조회 카탈로그와 도구 설명에서 제공하는 기간, 지표 정의, 필터와 사용 가능한 원천을 먼저 확인한다.
- 공통 집계를 우선하고, 필요한 조합을 지원하지 않으면 허용된 원천을 조회한 후 계산한다. 원천으로도 계산할 수 없으면 부족한 항목을 설명한다.
- 날짜 범위, 시간대, 데이터 최신성과 집계 단위를 명시한다. 중복·누락·환불·비용 범위가 확인되지 않으면 가정으로 구분하고 근거 없이 수치를 만들지 않는다.
- 계산 과정과 출처를 설명하고 개인을 식별할 수 있는 정보는 불필요하게 노출하지 않는다.
