# Growth HealMe

Growth HealMe를 Codex에서 읽기 전용으로 조회·분석하는 플러그인입니다.

## 설치

1. Codex의 **플러그인 → 마켓플레이스 추가**를 엽니다.
2. 출처: `https://github.com/HealMe-AI/healme-plugins.git`
3. Git ref: `main`, Sparse 경로: 비워 둡니다.
4. 마켓플레이스에서 **Growth HealMe**를 설치합니다.
5. 플러그인 연결 화면에서 인증된 `@thehealme.kr` 회사 계정으로 로그인합니다.

GitHub 계정이나 GitHub 로그인은 필요하지 않습니다. Codex의 Git 저장소 다운로드 기능을 사용할 수 있는 환경이어야 합니다. ChatGPT 계정과 회사 데이터 연결 계정은 별개입니다. 같은 ChatGPT 워크스페이스 소속일 필요는 없습니다.

## 사용

`Growth HealMe로 어제 상품별 매출과 공헌이익을 비교해줘`처럼 기간과 조건을 지정합니다. 서버가 제공하는 매출·상품·광고·회원·쿠폰·목표 집계와 허용된 원천 조회를 사용할 수 있습니다.

## 인증과 권한

이 저장소에는 설치 설정, 아이콘, 일반 사용 지침만 들어 있습니다. 설치 파일은 누구나 받을 수 있지만 데이터 조회는 서버에서 회사 계정 인증과 조회 권한을 확인한 뒤 허용합니다. 데이터·설정 수정과 적재는 지원하지 않습니다. 비밀번호·토큰·DB 접속정보를 파일이나 대화에 입력하지 마세요.

## 업데이트

지원되는 Codex는 시작 시 Git 마켓플레이스의 새 버전을 자동으로 확인합니다. 인터넷 연결이 필요하며 배포 즉시 실행 중인 모든 앱에 반영되는 것은 아닙니다. 새 버전이 보이지 않으면 Codex를 완전히 종료한 뒤 다시 실행하세요.

기존 같은 주소의 마켓플레이스를 쓰던 경우도 그대로 사용할 수 있습니다. 갱신 오류가 지속되면 마켓플레이스를 제거하고 위 주소로 다시 추가하세요. 이미 조회한 결과나 회사 데이터는 변경되지 않습니다.
